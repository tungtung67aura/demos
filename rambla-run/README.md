# Rambla Run

Endless runner por la Rambla de Montevideo (HTML5 canvas, sin dependencias). PWA instalable y jugable offline.

- Tocá = saltar (dos veces = doble salto con mortal) · Deslizá ↓ = barrerte (en el aire: caída rápida + barrida)
- Teclado: ↑ / Espacio saltar · ↓ barrerte · P / Esc pausa
- Mates seguidos suben el combo (×2 a ×5); pasar raspando un obstáculo también suma. El termo verde da un escudo.

Publicar: subir la carpeta tal cual (rutas relativas), p. ej. a `https://tungtung67aura.github.io/demos/rambla-run/`.
Si cambiás archivos, subí `CACHE` en `sw.js` (rambla-run-v2…) para que los teléfonos instalados se actualicen.
